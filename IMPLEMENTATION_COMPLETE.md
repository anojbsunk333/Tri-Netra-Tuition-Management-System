## 🔧 Customization Tips

### Change Colors

Edit Tailwind classes in any component:

```jsx
from-blue-50 → from-teal-50
to-blue-100 → to-teal-100
text-blue-900 → text-teal-900
```

### Update Attendance Warning

Change line in Dashboard.jsx:

```javascript
const attendanceWarning = attendancePercent < 75; // Change 75 to your threshold
```

### Add More Quotes

Edit `motivationalQuotes` array in Dashboard.jsx

### Customize Stats Cards

Modify the stats grid section to add/remove cards
